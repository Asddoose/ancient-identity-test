# 穿越古代身份图鉴

> 如果带着现在的灵魂回到古代，你会是谁？

**在线体验：** https://asddoose.github.io/ancient-identity-test/

40 道生活化选择题，约 3 分钟，测出你的古代身份、武侠立绘与本命绝学。无需登录、无需后端。

## 新增内容

- **7 张原创武侠风角色立绘**：内嵌 SVG 绘制，不依赖外部图片
- **7 套武侠武学面板**：江湖名号、本命神兵、武学境界
- **本命绝学**：太虚弈天诀、山河镇岳掌、春风化雨笔、九霄孤鸿剑、醉月飞星诀、破阵龙城枪、归园听雨心法
- **被动天赋与特殊技**：每个身份 2 项江湖奇技
- **武学属性**：谋略 / 武力 / 心境 / 机缘
- 分享卡同步升级：加入江湖名号与本命绝学

## 功能

- 40 道生活化单选题，5 个章节各 8 题
- 7 个性格维度，自动评分并匹配历史人物
- 性格侧写、匹配理由、隐藏优势、趣味彩蛋、现代职业投影
- 武侠风角色立绘 + 江湖卷宗 + 武学属性
- 手机 / 电脑响应式布局
- 可保存 1080 × 1440 分享卡，可复制分享文案

## 技术说明

- 单文件 `index.html`，HTML / CSS / JavaScript 全部内联
- 无外部图片、字体、CDN，无后端
- 角色立绘为原创 SVG，分享卡通过 Canvas 生成

## 本地运行

直接双击 `index.html`。完整使用与发布说明见 [使用说明.md](使用说明.md)。

## 声明

本测试为趣味人格内容，不构成专业心理评估或历史诊断。历史人物仅作为性格意象使用。
