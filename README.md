# 穿越古代身份图鉴

> 如果带着现在的灵魂回到古代，你会是谁？

**在线体验：** https://asddoose.github.io/ancient-identity-test/

40 道生活化选择题，约 3 分钟，测出你的古代身份与隐藏天赋。无需登录、无需后端。

## 你会是哪一种

- 谋士 · 张良：幕后执棋人
- 帝王 · 武则天：天生中心位
- 文人 · 苏轼：人间生活家
- 侠客 · 荆轲：孤勇行动派
- 诗人 · 李白：人间逍遥客
- 将领 · 霍去病：破阵先锋
- 隐士 · 陶渊明：人间清醒客

## 项目内容

- 完整单文件网页 `index.html`，HTML / CSS / JavaScript 全部内联
- 40 道题目、7 个性格维度、自动评分与历史人物匹配
- 响应式布局，手机 / 电脑均可使用
- 结果页含性格侧写、匹配理由、隐藏优势、趣味彩蛋、现代职业投影
- 可保存 1080 × 1440 分享卡，也可复制分享文案

详细使用与发布说明见 [使用说明.md](使用说明.md)。

## 本地运行

直接双击 `index.html` 即可。上线可部署到任意静态托管。

## 声明

本测试为趣味人格内容，不构成专业心理评估或历史诊断。历史人物仅作为性格意象使用。
